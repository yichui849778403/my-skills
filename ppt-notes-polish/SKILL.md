# PPT 备注口语化润色

目标：让备注念起来顺口、不拗口、不像在朗读。

用户风格核心：**用最少的字把意思说清楚，同时保留自然的说话节奏。**

## 触发场景

- 用户要求改 PPT 备注、润色备注、口语化备注
- 备注读起来太棒读、不够自然
- 安全培训、技术培训等需要念稿的场景

---

## 核心能力

### 一、视觉空格 —— 念稿的锚点

在备注中插入空格，把句子拆成小块（1-3 字），作为念稿时眼球的落点。念错可以随口替换，不容易串行。

**空格加在哪里：**

- 动词和宾语之间："进行 整改"、"纳入 审批流程"
- 修饰词和中心词之间："临时 测试账户"、"统一的 密码策略"
- 术语两侧："弱口令"、"撞库手段"、"横向渗透"
- 主谓之间："攻击者 会利用"

**原则：** 每个空格块 1-3 字，宁可多加不少加。用户已有的空格不要删。

### 二、去"棒读感" —— 过渡词是元凶

清单式过渡词让人感觉在朗读清单，直接去掉或用更轻的词替代：

- 首先/第一/其次/第三 → 直接删，或转成自然列举
- 因此 → 所以
- 这意味着 → 也就是
- 以及 → 还有
- 接下来 → 直接删或"下面"
- 然而 → 但

### 三、念出来，不写出来 —— 缩短是本能

对着 PPT 讲的时候，说的话比写的话短。砍掉那些写出来有用、念出来拗口的词。判断标准只有一个：**去掉它，意思变了没？没变就砍。**

**常见的可砍项：**

- 多余形容词："严格的技术隔离" → "技术隔离"（去"严格"不影响意思）
- 累赘动词："进行排查" → "排查"、"开展调查" → "调查"
- 长词换短词："这起事件" → "这件事"、"完成了操作" → "做完操作"
- 可省略的"的/了/在"：视语感决定，不是铁律

**不该砍的：** 有些词看似多余，实际承担了节奏作用。比如"在面对...时"比"面对...时"顺，"比较容易"里"比较"起了缓冲。最终标准是念出来的感觉。

### 四、词汇替换 —— 书面的换成口说的

| 书面 | 口说 |
|------|------|
| 记录下来 | 记下来 |
| 以此实现 | 靠这种方式 |
| 并非是 | 不是 |
| 无法 | 没法 |
| 例如 | 比如 |
| 作为密码 | 当密码 |
| 方便记忆 | 好记 |

---

## 禁止做的

- 不加"吧/嘛/呢"等语气词
- 不加"你得/咱们"等过度口语化人称
- 不在句尾加带态度的收尾（"多一点都不给"之类）
- 不改变原文逻辑顺序和实质内容
- 不改动技术术语
- 不把"比较"一律改"很"、"在"一律删除——看节奏

## 工作流程

1. 读取 PPT 指定页面备注
2. 逐页展示原文和修改
3. 用户确认后写入
