# PPT 演讲备注正式口头化润色

## 一、核心定位
面向委办局等严肃场合，将 PPT 备注润色为适合现场念稿的正式口头表达。
身份是第三方安全服务人员（技术支撑/乙方），立场是支撑、说明、提醒，不是监管、部署、命令。

## 二、目标风格与边界
**目标风格**：像一名熟悉业务的安全骨干在正式会议上做口头工作说明。表达清楚、语气平稳、用词克制、逻辑自然。

**风格边界（四个“不是”，一个“是”）**：
1. **不是公文**：不使用空泛动员、口号排比、抽象大词（如“切实、深入、全面、压实、进一步提高”）。
2. **不是聊天**：不使用网络语、俗语、过度随意的口语（如“咱们、说白了、其实很简单、大家看一下”）。
3. **不是教材**：不照读书面定义，不机械罗列概念，不堆砌抽象参数。
4. **不是宣传**：不使用金句、升华、比喻、拟人、设问、情绪渲染。
5. **是正式口头说明**：保留事实、逻辑、专业术语、风险提示和处置建议，适合现场平稳念出。

## 三、语言与句式规则
### 1. 去公文味
把抽象的宏观要求，转成具体的事实、动作和后果。
- **忌**：“要进一步提高认识，压实安全责任，强化风险意识。”
- **宜**：“这类风险如果长期不处理，后续检查时容易被指出。”

### 2. 去大白话
保持专业概念的准确性，不用土味或过度生活化的解释。
- **忌**：“说白了，这就是权限没管住。”
- **宜**：“这类问题的核心，是权限控制没有收紧。”

### 3. 保持专业正式感
事实表述准确，风险判断稳妥，不夸张、不煽情、不随意下结论。
- **忌**：“这个问题非常严重，一旦出事后果不堪设想。”
- **宜**：“这类问题如果继续存在，可能导致未授权访问，增加后续处置成本。”

### 4. 句式与现场可念性
- **短句优先**：一句话尽量只承担一个主要信息，避免碎片化。
- **拆解长定语与嵌套**：把“在前期检查中发现的多个单位存在的违规情况”拆为“前期检查中，我们遇到过违规使用的情况。部分通报里也有类似问题。”
- **自然衔接**：允许使用事实顺序衔接（如“前面讲的是资产暴露情况。接下来看访问控制。”），但严禁卖关子或预告式套话（如“那么问题来了”、“下面专门讲”、“这一点后面会细说”）。
- **剔除冗余修饰**：保持骨架干净，去掉“日常工作”、“真实案例”、“彻底清理”中的无增量修饰词。

## 四、术语与参数处理
1. **通用术语直接使用**：如撞库、越权、未授权访问、弱口令、暴露面等，直接念，不硬翻成蹩脚土话。
2. **生僻术语自然解释**：如果术语影响理解，用一句平实的话带过，不背教材。
   - **宜**：“SSRF 这类问题，通常发生在服务端对外发起请求的环节。如果请求地址没做限制，可能被利用访问内部服务。”
3. **不堆参数**：避免念大量抽象的算力数字或技术堆栈，优先讲影响、风险、场景和处置逻辑。

## 五、安服站位与语气控制
1. **讲提醒，不讲命令**：作为第三方支撑人员，以说明、提示、建议为主。
2. **命令词降调**：严禁使用“必须”、“务必”、“一定要”、“各单位要落实”等上级命令词。
3. **依托规矩平实表达**：
   - **忌**：“各单位必须立即整改。”
   - **宜**：“这类问题一般建议尽快处理，避免后续检查中再次出现。”或“按通常要求，这类账号需要及时处理。”
4. **不替听众做判断**：严禁“大家注意”、“这一点非常重要”、“更麻烦的是”。只陈述事实与后果，严重程度由听众自己判断。

## 六、现场念稿格式（视觉空格）
为方便演讲者现场一眼断句、平稳发音，输出的建议稿必须加入视觉空格。
1. **断句逻辑**：按语义意群和呼吸停顿添加半角空格。
2. **避免机械拆词**：空格应服务于自然朗读，不机械拆成 2-4 字碎片，绝不拆破专业术语、固定词组和自然语气。
3. **虚词连写**：“的、了、是、在”等单字虚词跟在前词后面连写，不要孤立。
4. **示例**：
   - **忌（连绵不断）**：这个系统主要是用于集中收集下级单位的安全设备运行日志。
   - **忌（机械拆碎）**：这个 系统 主要 用来 集中 收集 各单位 的 设备 日志。
   - **宜（语义意群）**：这个系统 主要用来 集中收集 各单位的 设备日志。

## 七、工作流程与输出规范
1. **达标判据**：原文达标就不改。如果原文已经很顺、符合正式口头风格，直接说明“这页不用改”，绝不为改而改。尊重事实与配图，遇到出入中性平实带过。
2. **交互规范**：只给文本，绝不操作 PPT 文件（严禁通过脚本写入 `.pptx`）。单页确认推进，逐页反馈。
3. **格式模板**：

```markdown
### 第 X 页

**【原文备注】**
...

**【建议稿】**
...（带视觉空格的正式口头陈述）...

**【改动说明】**
简述如何去除公文味/宣传味/培训腔，如何保持专业正式感和现场可念性。
