# PPT 备注口语化润色

目标：让备注念起来顺口、不拗口、不像朗读。
受众：委办局领导和网信办，人多、场合严肃。

## 一、唯一标准与达标判据

**第一标准：自己念起来爽、不尴尬。** 逻辑复杂就展开讲，短而绕不如长而顺，不追求最短，也不把术语硬翻成大白话（翻译后往往更拗口）。

**原文已达标就不改。** 判断只问一句：改完是不是真的更顺。改不动、改了没差别，就如实说"这页不用改"。

**达标看内容，不看空格。** 原版备注自带拆字空格，空格 ≠ 已润色。要看内容有没有"念教材感"：
- 书面定义句（"长度是衡量密码强度的主要指标"）
- 精确数据堆砌（"6 位数 7000 亿种组合、12 张 RTX5090 跑 14 天"）
- 书面过渡词（首先/其次/因此/综上所述）
有这些就是"念教材"，要改。

**口语化的度**：落到"讲人话"（能查到、不用猜、拼出密码），别滑向"唠嗑"（凑一凑、全摆着、总该、跟着试这类）；拿不准就向平实克制靠一点（只指语气，不含书面套话）。

## 二、红线（不能碰）

1. **不互动**：不提问、不设问，全文陈述句。
2. **不说教**：听众是领导，不"要注意""必须做到"，只摆事实、讲后果。
3. **不谄媚**：语气平，情绪起伏小。
4. **不比喻**：生动修辞（"门没锁一推就开"）换平实事实。**但功能类比允许**——用听众熟悉的东西类比陌生技术（如向日葵/ToDesk 类比远程控制），是类比不是修辞比喻。
5. **不加语气词、不过度人称**：不用"吧/嘛/呢""你得/咱们"。
6. **不改逻辑和术语**：不改论证顺序、实质结论、技术术语。但句式可以重组——合并段落、补因果连接词、调整措辞，都不算改逻辑。

## 三、怎么讲（内容方向）

1. **可以重复正文**：名词、术语、例子照带照念。
2. **讲清楚怎么回事，不背定义**：讲"顺着键盘敲"，不念"依据键盘位置排列"。
3. **念完往外展开**：带出正文关键词后，补正文没写的背景、细节、代价。
4. **落到代价上**：听众记住的是"会导致什么、身边发生过什么"。
5. **术语直接念，不翻译**：撞库、凭证填充、密码复用直接念。
6. **陌生概念先讲"为什么"**：把因果链补全——本来是什么 → 为什么危险 → 怎么防。
7. **正文与听众实际不符时，迁就实际、措辞体面**：不照念正文、也不拆台，中性措辞带过，落到对听众有用的那句。

**术语 vs 概念的判定**：问一句"听众不知道这个词，整句话还听得懂吗？"——听得懂是术语（直接念），听不懂是概念（先讲为什么）。多引入的陌生概念要克制，一个论据说透即可，能砍就砍。

## 四、句子怎么组织

1. **因果接上**：有逻辑关系的两句不硬切，补连接词。
2. **序号保留，标题去掉**：第一类/第二步这类序号保留，但"一是…二是…"改"第一个/第二个"，阶段名/类别名这类书面标题去掉只留序号。
3. **段落不太碎**：步骤类合并成叙述流。
4. **句尾收住**：举例、分析完回扣主题，不戛然而止。
5. **去条目感**：并列页用"先/再/还有/最后"串联。
6. **条目页分级**：知识讲解型（攻击手段、5W1H）逐条展开；操作清单型（检查项、禁止事项）不逐条念，只点题 + 强调关键 1-2 条 + 收尾。

## 五、怎么改词

### 视觉空格（念稿锚点，不参与达标判断）
句子插空格拆成 1-3 字小块：动宾、修饰与中心词、术语两侧、主谓之间。

### 去棒读感（书面 → 口语）
- 首先/其次/最后 → 先/再/然后
- 因此 → 所以；这意味着 → 也就是；以及 → 还有；然而 → 但
- "不是 A，而是 B" → 单线叙述或拆两句
- 冒号 → 逗号，或用"就是/看"衔接
- 破折号 → 句号
- 公文腔：总的来说/综上所述 → 删；进入…环节 → 交给…去处理；根据…严重程度 → 看…有多严重；向…汇报 → 汇报给…；按照法律法规 → 按法律规定；统一由…渠道发布 → 听…统一安排

### 口语化 + 缩冗余
- 书面词换口语词：记录下来→记下来、以此实现→靠这种方式、并非是→不是
- 长句拆顺，砍不加分的形容词/累赘词（严格的技术隔离→技术隔离、进行排查→排查）
- 信息本体不缩：步骤、案例事实、关键限制、因果、术语

## 六、交付方式 —— 只给文本，不碰 PPT

禁止通过编辑器 SDK 写 PPTX（会损坏正文）。

0. 先预读前后几页 + 看配图：跨页拆分、连续页先摸清结构，避免把话说死；判断"备注与正文对不上"前，先看该页配图（正文文字可能只列要点，配图才是备注真正在讲的东西），必要时回原版核对。
1. 拿备注原文（用户粘贴或只读提取）。
2. 逐页给"原文 vs 建议"，等确认。
3. 最终按页码输出纯文本清单，用户自己贴进 PowerPoint。
