# 产出物模板规范

本文件定义数据分类分级 + 风险评估全流程各产出物的标准结构，保证不同单位、不同会话产出物一致。

## 1. 分类分级清单-修正版（xlsx）

列（14列，按此顺序）：
`ip | port | 实例名 | 数据库名 | 模式名 | 数据表名 | 字段名称 | 字段描述 | 表描述 | 数据类别 | 敏感级别(个保法) | 分级标识(四级) | 判定依据 | 建议管控措施`

- 数据类别：业务数据 / 个人身份信息 / 身份鉴别信息 / 个人通信信息 / 个人基本资料 / 车辆标识信息 / 个人位置信息 / 个人财产信息 / 个人生物识别信息 / 个人健康生理信息
- 敏感级别（个保法）：不敏感 / 低敏感 / 敏感 / 高敏感
- 分级标识（四级）：一级 / 二级 / 三级 / 四级
- 行颜色：一级白、二级黄、三级浅红、四级深红（越敏感越红）

## 2. 敏感字段清单-待人工确认（xlsx）

同上述 14 列，但只保留三级+四级（敏感+高敏感）字段，供人工逐条确认。

## 3. 分级防护现状核查表（xlsx）

列：`序号 | 检查维度 | 检查项 | 应然标准（合格线） | 核查方法（怎么查） | 现状 | 差距`

- 检查维度按 A~H 分组：身份鉴别与访问控制 / 敏感数据加密存储 / 加密传输 / 日志审计 / 数据备份恢复 / 数据脱敏 / 数据删除清除 / 个人信息保护管理
- 从「数据安全评估模板-默认版.md」（40项检查库）按该单位数据实际挑适用项生成，通常 12-16 项

## 4. 差距分析表（xlsx）

列：`编号 | 检查维度 | 检查项 | 现状 | 应然标准 | 差距结论 | 风险等级`

- 风险等级：高 / 中 / 符合（符合项标"符合"，等级"-"）
- 行颜色：高红、中黄、符合绿

## 5. 整改建议清单（xlsx，借鸿泰格式）

列（8列）：`编号 | 等级 | 风险问题 | 整改建议 | 责任建议 | 建议时限 | 验收证据 | 当前状态`

- 编号 R-01~R-0N
- 责任建议：信息化科 / 软件厂商 / 业务科室
- 状态默认"待整改"

## 6. 数据安全风险评估报告（精简版，4块结构）

```
1 概述（目的/依据/范围/对象/方法）
2 数据资产识别与分类分级结果（资产概况 + 分级分布表 + 敏感字段清单）
3 差距分析（核查范围 + 差距结果 + 高风险项表）
4 风险结论与整改建议（结论 + R-01~R-0N 整改清单表）
```

砍掉：威胁识别赋值、风险计算模型/公式、组织架构详述、业务域展开、个人信息保护子项逐条展开。

## 7. 数据分类分级管理制度（代拟稿，6章3附件）

```
第一章 总则 / 第二章 数据分类管理 / 第三章 数据分级管理
第四章 数据安全管控 / 第五章 监督与保障 / 第六章 附则
附件1 数据分类目录（单位定制，按业务域枚举大类）
附件2 数据分级方法（通用四级 + 判定标准表）
附件3 分级管控要求（通用：采集/传输/存储/处理/共享/开放/销毁 7环节×4级递进）
```

- 附件1 按单位业务定制（覆盖全部数据版图）；附件2、附件3 跨单位复用通用版（参照《镇江市生态环境数据分类分级管理规范》）。

## 分级框架（固定口径）

四级：一级不敏感 / 二级低敏感 / 三级敏感 / 四级高敏感。

- 一级：时间戳、id、标志位、统计数（无个人信息、可公开）
- 二级：一般业务数据（车型/费用/流程/单位名）
- 三级：敏感个人信息（手机号/姓名/车牌/邮箱/住址）
- 四级：强身份/生物识别/鉴权（身份证/驾驶证/密码/人脸底库/银行卡）

关键：敏感个人信息（个保法，管个人权益）≠ 重要数据（数安法，管公共利益）。委办局/一般单位数据基本是"一般数据"内部按敏感度分四级，不涉及"核心/重要数据"。
