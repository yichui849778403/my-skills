## 1. 个人信息保护风险识别

### 1.1 通用个人信息处理
| # | 评估目标 | 方法 | 要点 |
|---|---|---|---|
| 1 | 匿名化处理 | 技术测评 | 是否明确匿名化数据类目 / 有效性 / 归档 |
| 2 | 向他人提供个人信息 | 人员访谈 | 告知接收方信息 / 单独同意 / 范围一致 |
| 3 | 个人信息委托处理 | 人员访谈 | 合同约定 / 监督 / 返还删除 / 不转委托 |
| 4 | 个人信息保存 | 系统查验 | 最短必要期限 / 生物识别与身份信息分开存储 |
| 5 | 必要安全措施 | 文档查看 | 制度规程 / 加密去标识 / 操作权限 / 培训 / 合规审计 |
| 6 | 个人信息保护负责人 | 人员访谈 | ≥100万人处理者设负责人 / 公开联系方式 / 报送网信部门 |

### 1.2 移动互联网应用程序个人信息保护
- **App 评估**（人员访谈）：识别 App / 小程序 / 第三方SDK 风险隐患（询问使用情况，收集安装包/下载链接）

### 1.3 处理个人信息遵循合法诚信原则（人员访谈）
- 误导欺诈胁迫 / 非法收集使用加工传输 / 非法买卖公开 / 合法性事由 / 隐瞒功能不提示

### 1.4 个人信息同意（人员访谈）
- 取得同意（自愿/明确/知情） / 可便捷撤回 / 变更重新同意

### 1.5 处理个人信息遵循正当必要原则（人员访谈）
- 目的明确合理 / 最小影响方式 / 最小范围收集 / 不超范围

### 1.6 个人信息安全义务
- **安全应急**（文档查看）：预案 / 立即补救 / 通知个人和网信
- **保密协议**（文档查看）：签订 / 转岗离岗告知保密

## 2. 数据安全技术风险识别

### 2.1 数据脱敏
- **数据脱敏策略**（人员访谈）：规则 / 方法 / 限制；场景 / 流程 / 职责分工

### 2.2 数据防泄漏
- **数据防泄露策略**（人员访谈）：管理制度；公开渠道 / 开源网站 / 售卖情况核查

### 2.3 数据安全监控与审计
- **日志留存记录**（人员访谈）：重点环节（授权访问/批量复制/提供/公开/销毁/接口调用/导出下载）/ 字段（时间/账号/方式/IP/登录）/ 识别追溯 / 定期备份
- **数据安全风险监测**（人员访谈）：异常操作告警 / 异常流量告警
- **监控与审计策略**（人员访谈）：制度 / 异常指标（IP/账号/数据/场景）/ 全过程日志 / 审计范围覆盖每个用户 / 日志保护 / 审计员

### 2.4 数据接口安全
- **接口安全控制**（文档查看）：策略 / 调用审批 / 定期清查 / 敏感通道加密+时间戳 / 鉴别+签名+传输协议 / 接口日志+异常告警
- **对外接口安全**（文档查看）：互联网/合作方认证鉴权+监控 / API密钥安全存储

### 2.5 身份鉴别与访问控制
- **访问控制**（技术测评）：绕过风险 / 登录失败处理（结束会话/限次/抑制/超时）
- **权限授权情况**（系统查验）：权限分配表更新 / 与审批一致 / 无多余过期 / 无离职沉默
- **数据权限管理**（系统查验）：审批流程 / 角色分离（管理/使用/审计）/ 超权限审批 / 多人审批+审计（批量复制/下载/导出/修改/删除）
- **数据访问控制**（系统查验）：分级访问 / 身份认证 / 双因子 / 最小化授权 / 复杂度（≥8位+大小写+数字+特殊字符）+ 定期更换

## 3. 数据安全管理风险识别

### 3.1 数据安全应急（文档查看）
- 预案 / 定期演练 / 3年内事件处置记录 / 通知用户 / 监测处置 / 3日内通知利害关系人

### 3.2 数据安全组织
- **岗位设置**（人员访谈）：职责分离 / 接口人 / 专人专岗 / 特权账户双人双岗
- **组织架构**（文档查看）：责任部门+负责人 / 高层参与 / 专职部门或岗位

### 3.3 数据安全制度流程
- **制度管理**（文档查看）：制定评审发布审核更新 / 分发到岗 / 流程 / 定期审核
- **制度体系**（文档查看）：方针目标 / 分类分级 / 访问权限 / 全生命周期 / 应急 / 合作方 / 脱敏加密审计 / 操作规程

### 3.4 人员安全管理
- **数据安全培训**（文档查看）：培训计划 / 全员培训记录 / 关键岗≥1次/年专项培训+考核
- **转岗离岗**（文档查看）：权限终止变更 / 告知保密义务
- **保密协议**（文档查看）：全员签订 / 调离前告知+承诺书
- **人员录用**（文档查看）：背景调查 / 关键岗考核

### 3.5 数据分类分级管理
- **分类分级保护**（文档查看）：明确标识 / 全流程安全措施 / 变更审核 / 自动打标工具 / 国家行业制度
- **分类分级制度**（文档查看）：制度建设 / 分级方法 / 管理策略
- **数据资产管理**（系统查验）：清单 / 覆盖（数据库/大数据/云存储/PC/U盘）/ 即时更新 / 技术扫描 / 重要数据识别

### 3.6 数据安全评估（文档查看）
- 评估对象/内容/时间/机构 / 定期 / 内容覆盖（业务/活动/管理/技术/合规）

### 3.7 数据合作方管理
- **外包访问权限**（系统查验）：最小范围 / 测试环境 / 不允许批量外发 / 实时监督
- **合作协议约束**（文档查看）：合同 / 目的方式范围保密罚则
- **合作方管理机制**（文档查看）：机制 / 能力评估监督

## 4. 数据处理活动风险识别

### 4.1 数据删除安全
- **存储介质销毁**（人员访谈）：策略制度 / 对象流程方式 / 监控记录
- **数据删除安全管理**（人员访谈）：流程审批 / 业务下线删除 / 委托结束监督 / 多副本同步删除

### 4.2 数据使用和加工安全
- **开发测试**（人员访谈）：终端管理 / 外部组件评估 / 真实数据去标识 / 生产环境隔离
- **数据导入导出**（人员访谈）：评估审批 / 审计策略 / 定期审计 / 权限管理 / 介质加密要求
- **数据正当使用**（人员访谈）：授权 / 一致性 / 变更同意 / 伦理 / 用户画像风险 / 行政许可一致
- **使用和加工合法性**（人员访谈）：法律法规公德伦理 / 国家利益 / 非法获取出售 / 违法信息

### 4.3 数据传输安全性
- **传输网络安全**（系统查验）：冗余 / 防火墙IDS / 不经过第三方缓存（等保合规可认可）
- **传输技术安全**（系统查验）：个人信息和重要数据加密+完整性 / 鉴别+算法+密钥 / 记录审计

### 4.4 数据提供安全
- **提供安全技术**（系统查验）：对外加密 / 共享监控 / 水印签名 / 流量接收者记录
- **提供安全管理**（文档查看）：合法正当必要 / 合同协议 / 接收方监督
- **提供合法正当必要性**（文档查看）：法律法规 / 目的合理 / 最小范围 / 境外审查

### 4.5 数据存储安全
- **数据备份恢复**（人员访谈）：策略规程 / 定期备份+恢复 / 访问控制 / 完整性验证 / 灾难恢复演练
- **存储介质安全**（人员访谈）：定期检查 / 规范 / 资产标识 / 记录审计
- **逻辑存储安全**（技术测评）：账号权限+访问控制+日志+加密+版本升级 / 漏洞修复 / 限制高危操作 / 敏感加密存储 / 外部区域安全
- **数据存储适当性**（人员访谈）：期限设置 / 永久必要性 / 地理位置 / 异地存储（重要数据）

### 4.6 数据收集安全
- **自动化收集数据**（人员访谈）：合法 / 范围数量频率 / 性能影响（爬虫类）
- **间接采集数据安全**（人员访谈）：合同协议 / 合法性授权审核
- **数据收集合法正当性**（人员访谈）：合法授权 / 窃取风险 / 范围合规

## 复用指引（针对公务用车系统 / 政务单位）

| 类别 | 适用度 | 说明 |
|---|---|---|
| 1.个人信息保护 | **强适用** | 公务用车系统有姓名/手机号/身份证/车牌等敏感个人信息，全块适用 |
| 2.数据安全技术 | **强适用** | 全块适用，重点：身份鉴别与访问控制（2.5）+ 数据安全监控与审计（2.3） |
| 3.数据安全管理 | **强适用** | 全块适用，机关事务局作为使用单位需建制度（参照环境局 V1.1 模板） |
| 4.数据处理活动 | **部分适用** | 适用：4.1 数据删除（退租场景）、4.3 传输、4.5 存储、4.6 收集（间接采集）<br>弱适用/不适用：4.4 数据提供（基本不向外提供）、4.2 开发测试（外采系统才需要） |

**精简版报告「差距分析」章节的检查维度 = 上述四块去弱项 + 强项合并**，约 20-25 条检查项，对照机关事务局实际填写"现状/应然/差距/整改建议"四列。
