# 箭头与文字重叠防护指南

核心问题：连线（尤其带箭头）压住文字标签，导致文字不可读。本指南给出可执行的硬约束，适用于所有 show_widget SVG 图表。

## 一、黄金法则

1. **箭头尖端禁区**：marker 落点周围 **10px 半径** 的圆形区域内禁止出现任何文字。否则箭头三角形会盖住字。
2. **标注进留白 / 节点内**：地址、序号等注释优先放进节点框内部，或放进两列之间的留白 gap（空白列）；箭头只在目标节点边框前停止（留 ≥12px 间隙），绝不压进框内文字。
3. **白底衬底兜底**：凡文字可能与连线共区的（gap 内、节点旁、线侧注释），**先画一个 `fill="#ffffff"` 的 `<rect>` 衬底，再画文字**，彻底杜绝压字。这是最稳妥的防线。
4. **线与线 / 线与字净空**：文字与任何连线之间 ≥6px；同区两条线之间 ≥20px，避免糊在一起。

## 二、标注放置策略

- **序号 / 步骤注释**（如 "(1) 请求 / (2) 响应"）：放在连线**侧上方或侧下方**的留白处，用白底衬底；若必须靠近线，文字基线与线间距 ≥10px。
- **数据包地址标注**（如 "目的 192.168.1.20:5000"）：放在两列 gap（空白列）中，用白底衬底；**不要**放在箭头尖端正前方（会被箭头盖住）。目标节点内部已写的地址可同时保留。
- **节点内文字**：直接写在节点框内，箭头只到框边，不进框。

## 三、间距参数（叠加在 SVG 设计规范之上）

| 项 | 值 |
|----|-----|
| 箭头尖端禁区半径 | 10px（禁放文字）|
| 文字与连线最小净空 | 6px |
| 箭头到目标节点边框间隙 | ≥12px |
| 同区两线最小垂直距离 | ≥20px |
| 白底衬底四边外延 | ≥3px |

## 四、自查清单（出图前必过）

- [ ] 每个箭头尖端 10px 内无文字
- [ ] 每个文字标签上/下 6px 内无连线穿过（或已加白底衬底）
- [ ] 序号 / 地址注释不在箭头正前方
- [ ] 节点内文字不被进入框内的箭头覆盖
- [ ] 同区两条线垂直间距 ≥20px
